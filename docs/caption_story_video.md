# Caption Story Video Endpoint

The `/story_video` route compiles a short MP4 using provided images and captions.
Send a `POST` request with JSON like:

```json
{ "images": ["/path/one.png"], "captions": ["A view of the park"] }
```

Each image is shown for a few seconds with its caption overlaid. To control
timing, send a ``frames`` list instead:

```json
{
  "frames": [
    {"image": "/path/one.png", "caption": "A view", "duration": 2}
  ]
}
```

This structure can be generated by an LLM that determines ordering and
durations.

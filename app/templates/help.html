Glimpser Help

{% call card('Getting Started') %}

Glimpser monitors webpages and cameras. To begin, open Settings and choose the Discover tab. Fill in the Add Camera form and click Submit.

{% endcall %} {% call card('Example: time.gov Template') %}

Follow these steps to create a time.gov template.

  1. Open the Discover tab to access the Add Camera form.
  2. Enter the following values:
    • Template Name: "US Official Time"
    • URL: "https://time.gov"
    • Frequency: 60 minutes
    • Dedicated XPath: //div[@id='time-display']
  3. Submit the form to create the template.
{% endcall %}
{% call card('Managing Templates') %}

You can manage templates from the dashboard.

  • View all templates in a grid.
  • Click a template to see details and recent captures.
  • Edit or delete from the template page.
{% endcall %} {% call card('Viewing Captures') %}

Ways to review your captures:

  • The home page shows the latest capture for each template.
  • Select Live for real-time updates.
  • Check Captions for AI descriptions.
{% endcall %} {% call card('Using the CLI') %}

Control Glimpser from the command line. Run glimpser --help to list all commands.

Setting Explanation
API_KEY Generated by the platform

This key is automatically generated and cannot be changed through the interface. Run generate_credentials to create a new one.

CHATGPT_KEY Required for ChatGPT features

The application only performs AI captioning or summarization when this key is provided.

DATABASE_PATH Location of the SQLite database

Defaults to data/glimpser.db. Change this if you relocate the database file.

PORT Web server port

The application listens on this port. The default is 8082.
USER_NAME Interface login user

Default username for logging in. Combine with USER_PASSWORD_HASH for authentication.

MAX_WORKERS Concurrent worker threads

Controls how many capture jobs run in parallel. Set close to the number of cameras you poll.

LLM_CAPTION_PROMPT Prompt for image captioning

Used when generating captions for screenshots.
LLM_SUMMARY_PROMPT Prompt for daily summaries

Guides how the language model summarizes multiple captions.
MAX_RAW_DATA_SIZE Raw data threshold

Maximum total size, in bytes, that raw images and videos may use before older files are purged.

MAX_IMAGE_RETENTION_AGE Image retention days

Images older than this many days are deleted automatically.
MAX_VIDEO_RETENTION_AGE Video retention days

Videos older than this limit are removed to conserve space.
MAX_COMPRESSED_VIDEO_AGE Archived video age

Compressed videos older than this many days are deleted.
MAX_IN_PROCESS_VIDEO_SIZE Temporary video size cap

Upper limit on in-process video size before capture is aborted.
LOG_LEVEL Python logging level

Sets the verbosity for internal logs. Examples: INFO, WARN, DEBUG.

FFMPEG_PATH Location of the FFmpeg binary

Override this if FFmpeg isn't in your system path.
FFMPEG_THREADS Threads for video processing

Number of threads FFmpeg should use while encoding or decoding.
HEALTH_STATUS_ALWAYS_VISIBLE Keep status icon visible

Show the System Performance indicator even when all metrics look normal.

LIVE_FALLBACK_FPS Frame rate for still image streams

Used when the live view falls back to periodic screenshots. Increase if your hardware can keep up.

LIVE_MAX_FAILURES Max retries for live streams

If FFmpeg fails this many times in a row, the connection closes and the job is aborted.

CHYRON_SPEED Duration of caption chyron

Controls how long the banner scrolls across the top of the page. Set to 0 to disable.

EMAIL_ENABLED Toggle email notifications

Set to True to enable email alerts using the SMTP settings below.

SMS_ENABLED Toggle SMS notifications

Set to True to send SMS alerts via Twilio.
CAP_ENABLED Toggle CAP notifications

Set to True to send Common Alerting Protocol messages.

EMAIL_SMTP_SERVER SMTP server address

Hostname of the mail server used to send notifications.
EMAIL_RECIPIENTS Notification recipients

Comma-separated list of email addresses that receive alerts.
TWILIO_SID Twilio account SID

Required for sending SMS alerts through Twilio.
TWILIO_TOKEN Twilio authentication token

Use along with TWILIO_SID to authenticate API requests.

TWILIO_NUMBER Sending phone number

The Twilio phone number messages are sent from.
NAV_ICON Navigation logo path

Relative path to the image shown in the navigation bar. Upload a custom PNG from the Interface tab or choose the default option to reset.

UA User-Agent string

Browser identifier sent when requesting remote pages.
